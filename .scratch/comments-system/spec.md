# Спецификация: система комментариев на Yii2

Домашнее задание #php. Гость оставляет комментарий без входа, и тот сразу появляется в ленте. Админ входит в админку, видит список комментариев, правит их текст, удаляет и восстанавливает. Новые и изменённые комментарии приходят в админку в реальном времени по WebSocket. Всё работает в Docker. Тесты разбиты на четыре набора (unit, smoke, e2e, regression), и для каждого есть объяснение. На ревью один комментарий проводится от формы до админки, и на каждом шаге показывается тест, который его фиксирует.

## Источники решений

- Язык предметной области: `GLOSSARY.md`.
- Как пишутся тесты и код (double-loop TDD по вертикальным срезам), покрытие, запреты обходов: `docs/adr/0001-double-loop-tdd.md`.
- WebSocket, авторизация токеном, коды закрытия: `docs/adr/0002-websocket-one-time-token.md`.
- Тест-планы с ID сценариев, карта классов, маршруты, схема БД, ярусы данных, линтеры, матрица P1–P13: `docs/test-plans/`.
- Тексты сообщений: `docs/test-plans/messages.md`.
- Правила написания автотестов: `docs/test-plans/rules.md`.

## Срезы

Работа идёт вертикальными срезами (см. ADR 0001). Каждый срез проводит одно поведение через все слои вместе с тестами: сначала приёмочный e2e среза (внешний цикл), потом unit и regression по одному тесту через red → green → refactor (внутренний цикл). Сквозной сценарий E2E-01 пишется во втором срезе и зеленеет по шагам.

| Тикет | Срез | Шаги пути | Внешний тест | Место падения E2E-01 после среза |
|---|---|---|---|---|
| 01 | Каркас, стенд, линтеры, CI | | `make check` на пустых наборах | ещё не написан |
| 02 | Вход админа и список | P1, P2 | E2E-01 шаги 1–2, SMOKE-02, SMOKE-03 | шаг 3 |
| 03 | Гость публикует комментарий | P4–P7 | E2E-01 шаги 3–4, SMOKE-01 | шаг 5 |
| 04 | WS-подключение админки | P3 | E2E-01 шаг 5, SMOKE-04 | шаг 6 |
| 05 | Новый комментарий вживую | P8–P10 | E2E-01 целиком, E2E-05, E2E-07 | зелёный |
| 06 | Правка, удаление, восстановление | P11–P13 | E2E-02, E2E-03, E2E-04 | зелёный |
| 07 | Logout, блокировка и смена пароля гасят доступ | | E2E-06 | зелёный |
| 08 | Недопустимые символы вырезаются, а не блокируют отправку | P5–P7, P11 | REG-G-18, REG-A-42 | зелёный |
| 09 | Повторный прогон на том же стенде (ИЗ-1) | | `make test-rerun` | зелёный |
| 10 | Дыры в покрытии: XSS в HTML-админке, переподключение WS, контракт JSON | P2, P3, P10 | REG-A-34, E2E-08 | зелёный |
| 11 | Готовность к ревью | P1–P13 | ручной проход по матрице | зелёный |

Каждый тикет закрывается `/code-review` среза.
