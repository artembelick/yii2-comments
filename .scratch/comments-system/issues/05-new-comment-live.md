# 05: Новый комментарий появляется в админке вживую

**What to build:** после публикации комментария событие «создан» уходит в Redis, WS-сервер рассылает его авторизованным админкам, и строка появляется первой в списке без перезагрузки, с подсветкой. Если админ не на первой странице, вместо строки появляется баннер «N новых». После переподключения список перечитывается. С этим срезом путь комментария от формы до админки работает целиком.
