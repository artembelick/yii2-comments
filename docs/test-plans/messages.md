# Каталог сообщений

Тесты проверяют тексты дословно. Тот же каталог лежит в `tests/_data/messages.json`, тесты всех наборов читают его оттуда. Код берёт тексты из файлов переводов Yii i18n: язык только `ru-RU`, одна категория `app`. Тест UNIT-MSG-01 проверяет, что ключи и тексты в обоих местах совпадают.

## Валидация

На поле показывается одна ошибка, первая по порядку проверок: тип → обязательность → недопустимые символы → многострочность → длина.

| Ключ | Текст |
|---|---|
| `field.invalid` | Некорректное значение. |
| `name.required` | Укажите имя. |
| `name.invalid_chars` | Имя содержит недопустимые символы. |
| `name.multiline` | Имя должно быть в одну строку. |
| `name.too_short` | Имя должно быть не короче 2 символов. |
| `name.too_long` | Имя должно быть не длиннее 64 символов. |
| `text.required` | Напишите комментарий. |
| `text.invalid_chars` | Комментарий содержит недопустимые символы. |
| `text.too_long` | Комментарий должен быть не длиннее 2000 символов. |

## Публичная часть

| Ключ | Текст | Где |
|---|---|---|
| `feed.empty` | Пока нет комментариев. | Пустая лента |
| `comment.created` | Комментарий опубликован. | Флэш после отправки |
| `comment.rate_limited` | Слишком много комментариев. Попробуйте через минуту. | Ответ 429 |

## Вход

| Ключ | Текст |
|---|---|
| `login.username_required` | Укажите логин. |
| `login.password_required` | Укажите пароль. |
| `login.invalid` | Неверный логин или пароль. |
| `login.too_many_attempts` | Слишком много попыток входа. Попробуйте через 15 минут. |
| `login.unavailable` | Вход временно недоступен. Попробуйте позже. |

## Интерфейс

Подписи полей, кнопки и заголовки. Тесты находят по ним элементы через роль и доступное имя (правило БР-1), поэтому эти тексты тоже часть контракта.

### Публичная часть

| Ключ | Текст | Где |
|---|---|---|
| `feed.title` | Комментарии | Заголовок страницы (h1) и подпись области ленты |
| `form.title` | Оставить комментарий | Заголовок формы |
| `form.name` | Имя | Подпись поля |
| `form.text` | Комментарий | Подпись поля |
| `form.submit` | Отправить | Кнопка |
| `pager.label` | Страницы | Подпись навигации (`nav aria-label`) |
| `pager.prev` | Назад | Ссылка пагинации |
| `pager.next` | Вперёд | Ссылка пагинации |

### Вход

| Ключ | Текст | Где |
|---|---|---|
| `login.title` | Вход в админку | Заголовок страницы (h1) |
| `login.username` | Логин | Подпись поля |
| `login.password` | Пароль | Подпись поля |
| `login.submit` | Войти | Кнопка |

### Админка

| Ключ | Текст | Где |
|---|---|---|
| `admin.title` | Комментарии | Заголовок списка (h1) |
| `admin.logout` | Выйти | Кнопка в шапке |
| `admin.col.author` | Автор | Заголовок колонки |
| `admin.col.text` | Текст | Заголовок колонки |
| `admin.col.created` | Создан | Заголовок колонки |
| `admin.col.audit` | Изменения | Заголовок колонки |
| `admin.col.actions` | Действия | Заголовок колонки |
| `admin.action.edit` | Редактировать | Ссылка в строке |
| `admin.action.delete` | Удалить | Кнопка в строке |
| `admin.action.restore` | Восстановить | Кнопка в строке |
| `admin.edit.title` | Редактирование комментария | Заголовок страницы правки (h1) |
| `admin.edit.author` | Автор | Подпись поля (только для чтения) |
| `admin.edit.text` | Текст | Подпись поля |

| `admin.edit.cancel` | Отмена | Ссылка обратно в список |
