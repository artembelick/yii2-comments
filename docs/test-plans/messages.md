# Каталог сообщений

Тесты проверяют тексты дословно. Тот же каталог лежит в `tests/_data/messages.json`, тесты всех наборов читают его оттуда. Код берёт тексты из файлов переводов Yii i18n: язык только `ru-RU`, одна категория `app`. Тест UNIT-MSG-01 проверяет, что ключи и тексты в обоих местах совпадают.

## Валидация

На поле показывается одна ошибка, первая по порядку проверок: тип → обязательность → длина. Недопустимые символы не ошибка: нормализатор вырезает их до валидации ([правила очистки](unit.md#commontextcommenttextnormalizer)).

| Ключ | Текст |
|---|---|
| `field.invalid` | Некорректное значение. |
| `name.required` | Укажите имя. |
| `name.too_short` | Имя должно быть не короче 2 символов. |
| `name.too_long` | Имя должно быть не длиннее 64 символов. |
| `text.required` | Напишите комментарий. |
| `text.too_long` | Комментарий должен быть не длиннее 2000 символов. |

## Страницы ошибок

Ошибка HTML-страницы показывается своим видом в layout части (`common\web\ErrorPage`, REG-G-24, REG-A-55). Заголовок и текст берутся по коду ответа. Код вне таблицы получает тексты своего класса: 4xx — как 400, 5xx — как 500. Текст исключения показывается только у 409: это `admin.edit_deleted`. У остальных кодов текст общий, потому что сообщения фреймворка (CSRF, метод, маршрут) не для людей. JSON-эндпоинты `/api/*` этот вид не получают (REG-A-61b).

| Ключ | Текст | Где |
|---|---|---|
| `error.400.title` | Некорректный запрос | Заголовок страницы ошибки 400 |
| `error.400.text` | Запрос не удалось обработать. Вернитесь назад, обновите страницу и попробуйте ещё раз. | Текст страницы ошибки 400 |
| `error.403.title` | Доступ запрещён | Заголовок страницы ошибки 403 |
| `error.403.text` | У вас нет доступа к этой странице. | Текст страницы ошибки 403 |
| `error.404.title` | Страница не найдена | Заголовок страницы ошибки 404 |
| `error.404.text` | Такой страницы нет: возможно, адрес набран с ошибкой. | Текст страницы ошибки 404 |
| `error.405.title` | Запрос не поддерживается | Заголовок страницы ошибки 405 |
| `error.405.text` | Этот адрес не принимает такой запрос. | Текст страницы ошибки 405 |
| `error.409.title` | Действие сейчас невозможно | Заголовок страницы ошибки 409 |
| `error.409.text` | Действие конфликтует с текущим состоянием данных. | Текст страницы ошибки 409, если в исключении нет своего текста |
| `error.429.title` | Слишком много запросов | Заголовок страницы ошибки 429 |
| `error.429.text` | Подождите немного и попробуйте снова. | Текст страницы ошибки 429 |
| `error.500.title` | Ошибка на сервере | Заголовок страницы ошибки 500 |
| `error.500.text` | Что-то пошло не так. Попробуйте позже. | Текст страницы ошибки 500 |
| `error.back.home` | На главную | Ссылка назад на странице ошибки публичной части |
| `error.back.list` | К списку | Ссылка назад на странице ошибки админки |
| `error.back.deleted` | К удалённым комментариям | Ссылка на вкладку «Удалённые» на странице ошибки 409 админки |

## Консоль

Команды `admin/create`, `admin/block`, `admin/unblock`, `admin/password` (UNIT-CLI-01…03). Ошибки печатаются в stderr по одной на строку.

| Ключ | Текст | Где |
|---|---|---|
| `cli.admin.created` | Админ {username} создан. | stdout после создания |
| `cli.admin.username_invalid` | Логин: от 3 до 64 символов, только латиница, цифры, «_», «.» и «-». | stderr |
| `cli.admin.username_taken` | Логин {username} уже занят. | stderr |
| `cli.admin.password_too_short` | Пароль: не короче {min} символов. | stderr |
| `cli.admin.blocked` | Админ {username} заблокирован. | stdout после блокировки |
| `cli.admin.unblocked` | Админ {username} разблокирован. | stdout после разблокировки |
| `cli.admin.password_changed` | Пароль админа {username} изменён. | stdout после смены пароля |
| `cli.admin.not_found` | Админа {username} нет. | stderr, код 2 |
| `cli.admin.ws_not_notified` | Изменение для админа {username} сохранено, но WS-сервер о нём не узнал: Redis недоступен. Открытые WS-соединения админа закроются при следующей проверке доступа, в течение минуты. | stderr, код 3: `admin/block` или `admin/password` сохранены, публикация `access.revoked` упала |

## Интерфейс

Подписи полей, кнопки и заголовки. Тесты находят по ним элементы через роль и доступное имя (правило БР-1), поэтому эти тексты тоже часть контракта.

### Публичная часть

| Ключ | Текст | Где |
|---|---|---|
| `feed.title` | Комментарии | Заголовок страницы (h1) и подпись области ленты |
| `form.title` | Оставить комментарий | Заголовок формы |
| `form.name` | Имя | Подпись поля |
| `form.text` | Комментарий | Подпись поля |
| `form.submit` | Отправить | Кнопка |
| `pager.label` | Страницы | Подпись навигации (`nav aria-label`) |
| `pager.prev` | Назад | Ссылка пагинации |
| `pager.next` | Вперёд | Ссылка пагинации |

### Вход

| Ключ | Текст | Где |
|---|---|---|
| `login.title` | Вход в админку | Заголовок страницы (h1) |
| `login.username` | Логин | Подпись поля |
| `login.password` | Пароль | Подпись поля |
| `login.submit` | Войти | Кнопка |

### Админка

| Ключ | Текст | Где |
|---|---|---|
