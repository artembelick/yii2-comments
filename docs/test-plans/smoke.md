# Smoke

**Зачем:** за десятки секунд понять, что стенд жив, до запуска длинных наборов. Если smoke красный, остальные наборы не запускаются.
**Как:** Playwright, браузер Chromium. Тесты только читают и входят в систему, данных не создают, поэтому их можно запускать на любом стенде, включая prod.
**Когда:** сразу после подъёма стенда, в `make check` первым из интеграционных наборов, в CI на каждый PR и после каждого деплоя.
**Предусловие:** админ для smoke, один на стенд. Его создаёт `make admin`, а логин и пароль берутся из env. Smoke запускается до ярусов и других данных не создаёт.

| ID | Сценарий | Ожидаемый результат | Что значит падение |
|---|---|---|---|
| SMOKE-01 | Открыть публичную часть | 200, есть форма комментария и блок ленты | Лежит nginx, php-fpm или frontend |
| SMOKE-02 | Открыть страницу логина админки | 200, есть форма входа | Лежит backend |
| SMOKE-03 | Войти админом для smoke | Открылся список комментариев, вкладка «Активные» | Нет БД или миграций, сломаны сессии |
| SMOKE-04 | Остаться на списке после входа | Индикатор WS переходит в «онлайн» за 5 секунд | Лежит ws или Redis, не выдаётся токен, nginx не проксирует `/ws` |
